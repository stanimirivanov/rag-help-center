# RAG Help Center

A backend-only RAG (retrieval-augmented generation) reference system for a
help-center use case, built to demonstrate the modern Kotlin + Spring
ecosystem (Boot, Data, Cloud, AI, gRPC, Security, Kafka), Hexagonal
architecture, CQRS, multiple database technologies, k8s deployment, and
Grafana-stack observability.

## Local development

```bash
docker-compose up -d
./mvn install
```

See `docs/` for the full design and implementation plan.
